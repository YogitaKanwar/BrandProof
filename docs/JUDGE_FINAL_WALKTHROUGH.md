Start at **https://brandproof-round3-preview-20261102.onrender.com/#/demo**. No password or registration is required. Use fictional content only. ## 3. Content: save deliberate conflicts

The example caption/poster show INR 599 while confirmed references require INR 899. Its caption also has other deliberate errors. Save your edits before **Run review**; unsaved drafts disable review. The tested candidate prevents the underlying loading/revision race but is not deployed. ## 4. Results: follow actual evidence

Run the real engine. Inspect caption price/date/wording findings and poster price OCR boxes. Open the confirmed source/version citation behind each supported finding. For the visual promise, import/confirm the extended directives, run with a reliably flat poster, and inspect observed/target colour, CIE76 distance/tolerance, OCR foreground/background and contrast/threshold. Add an actual description including visible price/date text. Complex images or incomplete OCR remain partial, with human-inspection scope. A matching rule or zero findings is not approval.

To try aligned caption text: **An affordable workshop on 2026-11-12. Book for INR 899. Terms apply.** Save and rerun. The sample poster still says INR 599; correcting the caption alone does not fix that image.

## 5. Human Review: make a real recorded choice

Request human review as the synthetic Creator. Use the demo's eligible Reviewer controls, inspect the actual findings and record a reasoned decision. Request changes while the sample conflicts remain. To demonstrate approval, resolve/disposition the actual findings first, request the current snapshot, and supply genuine manual-check notes for each incomplete scope. Do not copy QA notes as if they were your inspection or claim independent human sign-off. Self-approval/revision rules still apply.

After an eligible approval, change saved content, description or source/profile. The old receipt becomes stale and remains historical. Source confirmation and a reviewer finding disposition are not interchangeable with final content approval.

## 6. Governance Insights: inspect the denominator

Open **Governance Insights**. Review actual categories, campaign counts, exact source versions, latest dispositions/reasons and saved-evidence links. A new demo normally shows **Insufficient sample**. No rate/recommendation appears for fewer than five distinct reviewed campaign/content revisions in that source-version group. Re-running unchanged content does not inflate the sample or carry prior decisions forward. An insight link opens the exact saved run/finding/source version. A signal asks an owner to investigate; it is not permission to weaken regulation.

## 7. Return, remove, reset and exit

Use the wordmark to return to Your reviews, then reopen the saved campaign. Refresh preserves the valid sandbox, saved history and deep links. Try owner **Delete → Cancel**, then **Confirm delete → Undo delete** on your own fictional test campaign. Removal retains audit history; Undo is in-page only and is lost on reload. Reset has its own confirmation and revokes the old workspace's roles. Exit Demo logs out/revokes access. Neither is production data erasure. A separate judge context cannot read your records.
